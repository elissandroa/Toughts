# 🧠 Toughts

Seja bem-vindo(a) ao **Toughts**!  
Um espaço onde você pode compartilhar, explorar e refletir sobre pensamentos, ideias e inspirações.

---

## ✨ Sobre o Projeto

O **Toughts** é uma aplicação web desenvolvida para quem gosta de registrar ideias, pensamentos ou inspirações do dia a dia. O objetivo principal é criar uma rede social minimalista, onde cada usuário pode expressar seus pensamentos em um ambiente amigável e intuitivo.

---

## 🚀 Funcionalidades

- ✍️ Cadastro e login de usuários  
- 💬 Compartilhamento de pensamentos  
- 🔍 Pesquisa de pensamentos por palavras-chave  
- 📜 Listagem de pensamentos mais recentes  
- 📝 Edição e exclusão dos próprios pensamentos  
- 🎨 Interface simples e responsiva

---

## 🛠️ Tecnologias Utilizadas

- **JavaScript**  
- **Handlebars**  
- **CSS**  
- **Node.js** (backend)  
- **Express.js** (servidor web)  
- **MongoDB** (banco de dados)

---
## ⚙️ Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/elissandroa/Toughts.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd Toughts
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Configure as variáveis de ambiente (exemplo no arquivo `.env.example`).
5. Inicie o servidor:
   ```bash
   npm start
   ```
6. Acesse no navegador:  
   [http://localhost:3000](http://localhost:3000)
